# ELLOOL Local Engine

محرك اختياري لتوليد الصور والفيديو الحقيقي محليًا على كمبيوتر المستخدم، وليس خدمة API لتوليد الصور.

## التشغيل

1. ثبّت Python 3.10 أو أحدث (64-bit) على كمبيوتر Windows / Linux / macOS.
2. افتح Terminal داخل هذا المجلد وشغّل:

```bash
python ai_studio.py
```

3. عند أول تشغيل سيحاول الملف تثبيت المكتبات الناقصة، ثم ينشئ مفتاح ربط محليًا ويطبعه في نافذة التشغيل. احتفظ بالمفتاح.
4. افتح موقع ELLOOL من **نفس الكمبيوتر**.
5. اذهب إلى الإعدادات ← محرك الصور المحلي، وضع العنوان `http://127.0.0.1:8000` والمفتاح، ثم اضغط «اختبار الاتصال».
6. افتح استوديو الصور واختر «محرك ELLOOL المحلي».

## النماذج

- NVIDIA GPU بذاكرة 16GB أو أكثر: يحاول استخدام FLUX.1-schnell للصور.
- الأجهزة الأخرى: يستخدم Stable Diffusion 1.5 بوضع أخف، وقد يكون بطيئًا جدًا على CPU.
- الفيديو الحقيقي يستخدم Wan2.1 فقط مع NVIDIA GPU وذاكرة 16GB+؛ نجاحه غير مضمون على كل بطاقة. لا يستبدل النظام الفيديو الحقيقي بمونتاج صور.

## الخصوصية والاتصال

- التوليد يتم على الكمبيوتر بعد تنزيل أوزان النموذج أول مرة من مستودعات النماذج العامة.
- لا يرسل هذا المحرك أوصاف التوليد إلى API خارجي.
- يستمع الخادم على `127.0.0.1` فقط، ويتطلب مفتاحًا عشوائيًا محفوظًا في `.ellool_engine_key`.
- لا ترفع المنفذ إلى الإنترنت ولا تغيّر عنوان الاستماع إلى `0.0.0.0`.
- يجب فتح ELLOOL والمحرك على نفس الكمبيوتر؛ فتح الموقع من التابلت لن يجعل التابلت يستخدم محرك كمبيوتر آخر.

## حدود الإصدار الأول

- إنشاء الصور من وصف نصي.
- لا يدعم تعديل صورة مرجعية عبر المحرك المحلي بعد.
- لا يعمل على Vercel؛ يجب تشغيله على جهاز المستخدم.
- يتطلب مساحة تخزين واتصالًا أوليًا لتنزيل أوزان النماذج، وGPU مناسبًا للأداء الجيد.
